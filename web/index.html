Why UtilDroid

Install once. It keeps itself up to date.

Silent background updates

When a new version is published, the store downloads and installs it on its own. No confirm taps on Android 12 and newer.

Checked before install

Every download is verified by checksum and signing key. Anything that doesn't match is blocked.

You set the pace

Check every 6, 12 or 24 hours, or turn checks off. Wait for Wi-Fi if you like.

Open and free

Every release lives on public GitHub, and the store's code is open. No servers, no fees, no tracking.

No account needed

No sign-in, no profile. Open the store and install.

How it works

Up and running in three steps

  1. 1

    Download the APK

    Open this page on your phone and tap Download. It grabs the latest release from GitHub.

  2. 2

    Allow installs

    Android asks once to let UtilDroid install apps. Say yes, and allow notifications too.

  3. 3

    Pick your apps

    Tap Install on the ones you want. From then on, updates arrive by themselves.

Questions

Why isn't it on the Play Store?+

These are personal utilities, built for a small circle. Publishing on GitHub keeps them free, ad-free and quick to update.

Is it safe to install?+

The store only installs APKs signed with one known key, and checks every file's checksum first. The store's source code is public for anyone to read.

Which phones does it work on?+

Any Android phone running Android 8.0 or newer. Silent updates need Android 12 or newer.

Does it cost anything?+

No. The store and every app in it are free, with no ads and no in-app purchases.
